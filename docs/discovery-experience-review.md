# Salud 6.3：探索與閱讀體驗改善

日期：2026-11-06。沿用 React／Vite 與 GitHub Pages，未加入帳號或追蹤服務。

## 研究與規劃

目標是讓沒有醫學背景的讀者，也能從生活問題走入深度內容。盤點後的主要問題為首頁重複入口過多、專科標題過密、課程前的大表格延後閱讀、入口下載過多章節資料，以及對實證分級與無障礙檢查的過度宣稱。

參考 CDC 的清楚溝通原則，以主要訊息、明確行動、讀者情境與資訊分層安排內容；參考 MedlinePlus 的健康資訊辨識原則，讓來源、限制與網站用途可查。這是設計依據，不代表獲得上述機構認證。

- [CDC Clear Communication Index](https://www.cdc.gov/ccindex/tool/how-to-use.html)
- [MedlinePlus：Evaluating Health Information](https://www.medlineplus.gov/evaluatinghealthinformation.html)
- [GRADE 方法](https://book.gradepro.org/guideline/overview-of-the-grade-approach)
- [WHO：身體活動](https://www.who.int/news-room/fact-sheets/detail/physical-activity)
- [CDC：睡眠](https://www.cdc.gov/sleep/about/)
- [AASM／SRS：成人睡眠時數共識](https://aasm.org/resources/pdf/pressroom/adult-sleep-duration-consensus.pdf)

## 執行與迭代

1. 首頁以「短課 → 主題 → 依問題推薦 → 行動 → 實證 → 工具」形成可自由跳讀的路徑。完整資料保留，預設只展示六個主題，分類與展開可找到全部 24 個入口。
2. 保留品牌森林綠，以較安靜的線條、留白、字級與本機 SVG 插畫建立一致視覺。支援原有五種配色與字級選擇，圖片不需額外下載。
3. 學習卡連到真實課程，時長與數量由資料計算。新增以既有課程題目驅動的小挑戰，提供解釋與延伸課程；不產生健康評分或診斷。
4. 課程頁將閱讀導覽、摘要、圖解、行動與延伸來源分清。課程比較表與臨床矩陣仍可展開閱讀。跳到段落時同步移動焦點。
5. 共用視窗、搜尋與手機選單加入焦點循環及關閉後返回原控制項；加入全域可見焦點與減少動態支援。手機頂欄減少同時顯示的工具，入口仍在目錄與工具區。
6. 實測 390px 與 320px 後，修正標題斷行、手機頂欄密度與觸控範圍；保留手機底部五個主要入口。
7. 為首頁三堂飲食、運動與睡眠入門課加入可點閱的官方／原始來源與適用限制；區分台灣與哈佛餐盤，並釐清掌心目測量不等於營養代換表的一份。改善睡眠與運動入門的過度確定用語。說明 A–E 是網站編輯閱讀標籤，不是假稱正式 GRADE；不宣稱未存在的具名醫療審閱。
8. 無障礙腳本改成如實的原始碼盤點；移除硬編碼的 100% 合規結果，明列需瀏覽器與人工驗證之處。
9. 分離輕量章節路由目錄，將完整章節、課程閱讀器與臨床矩陣延遲載入；提供載入與失敗處理。主要入口 JS 的 gzip 由本次第一輪建置的 598.12 KB 降至約 311 KB，約減少 48%。不包含共用 vendor，並非速度或 Core Web Vitals 測量。

# Salud 6.4：專區白話導讀、課程圖表校正與閱讀字級

日期：2026-11-10。

## 盤點發現

6.3 整理了首頁與課程頁，但讀者點進專區後落差很大：

1. **專區開場太專科。** 睡眠專區的標題是「睡眠神經生理、超晝夜架構、膠淋巴大腦沖刷與 CBT-I」，首段以驚嘆句羅列術語，旁邊是「旗艦支柱」「總樞紐」與數字徽章。壓力、抗老、健康生活、運動、飲食、保健品專區相同。
2. **徽章無法佐證。** 「100% 同行評審文獻」「Grade A 最高臨床推薦」「CEBM 1a 實證醫學等級」不是可查核的陳述；另有字樣暗示外部教育機構參與。
3. **課程圖表錯置。** 逐課比對標題後，17 堂課的圖解與對照表其實屬於相鄰課程（課程順序調整後，圖表仍綁在舊編號）。
4. **字太小且不隨設定縮放。** 全站約 1,570 處使用固定 9–11 px，另有約 1,800 處 12 px；固定像素不受「字級」設定影響。
5. **每頁共用同一個分頁標題**，瀏覽紀錄與書籤無法分辨。

## 做法

- 以共用元件 `HubHero` 與資料檔 `src/data/hubPrimers.ts` 重寫七個專區開場，順序依 CDC Clear Communication Index 的「主要訊息在前」：這頁講什麼 → 三個重點 → 入門小課 → 深入內容。資料檔開頭寫明用語規則，並以測試檢查長度、誇大用語與連結。
- 三個重點只寫本站既有內容已支持、且各國指引一致的陳述（例如成人睡眠 7–9 小時、每週 150–300 分鐘中等強度活動、慢性失眠第一線為 CBT-I、安心專線 1925）。
- 圖解與對照表依課程標題重新配對；對照表以 `LESSON_TABLE_KEY` 明示對應，沒有合適表格者不顯示。
- 小字改為 rem，並把 `text-xs`／`text-sm` 各加 1 px。SVG 圖內文字以座標排版，維持不動以免重疊。
- 導覽與分頁標籤改日常用語；每頁設定分頁標題。

## 驗證與限制

- 78 項測試、治理檢查、TypeScript 與正式建置通過。
- 依專案擁有者指示，本版**未做瀏覽器逐頁目視驗證**。字級放大可能讓個別窄卡片多換一行，尚未逐頁確認。
- 專區內部的深度段落（各分頁內容）仍保留原本的專科寫法，本版只改開場、分頁標籤與導覽；逐段白話改寫與醫學內容複核不在本次範圍。

# Salud 6.5：全站白話深化、運動專項導讀與互動學習升級

日期：2026-11-10。

## 盤點與優化目標

延續 6.4 的白話導讀原則，進一步消除進入各專區與運動分頁後的「術語斷崖（Jargon Cliff）」與介面不一致：

1. **三高、體重與人體系統專區補齊白話導讀**：`CardiometabolicHub`、`ObesityHub`、`HumanSystemsHub` 納入 `HUB_PRIMERS` 與 `HubHero`，並將總覽頁的驚悚口吻（「隱匿殺傷力」「殭屍細胞發炎風暴源！」）改寫為清楚、可行動的日常語言。
2. **運動專區（`#exercise`）全面升級為快樂學習體驗**：新增 `src/data/sportPrimers.ts`，提供「依目標挑運動」5 大情境推薦器，以及全部 9 大運動專項（運動生理、肌力重訓、伸展與活動度、跑步、自行車、登山健行、羽球、桌球、匹克球）的白話導讀卡（適合對象、3 個核心觀念、新手第一步、防傷提醒、配對 5 分鐘入門課）。
3. **統一全站分頁列與網址深連結**：`SleepHub`、`LongevityHub`、`MentalHealthHub`、`UltraHealthHub`、`DietaryPatternsHub`、`DisciplineTabBar` 統一改用支援鍵盤方向鍵與分組的 `HubTabBar`；修正 `#exercise/strength`、`#exercise/mobility`、`#ultrahealth/*`、`#diet/patterns` 的網址同步。
4. **首頁與課程總表互動升級**：首頁 `LearningChallenge` 擴充為 8 題跨領域題庫；`#learn` 課程總表新增上次閱讀續讀卡、關鍵字搜尋、完成狀態篩選、路徑收合與課堂重點筆記複製功能。
5. **無障礙與頁面收尾精簡**：`DietaryNutrientsView` 彈出視窗補齊 `useDialogFocus` 與 Escape 關閉；移除 `CourseShell` 臨床專區底部重複堆疊的 `FourPillarsClinicalMatrix`。

- 79 項單元／路由／內容完整性測試通過（含 10 個 `HUB_PRIMERS` 與 9 個 `SPORT_PRIMERS` 驗證）。

# Salud 6.6：最大肌力 × 肌耐力抗老科學專區・怪獸訓練體系整合與高雅介面優化

日期：2026-11-10。

## 盤點與優化目標

針對使用者對「肌耐力與最大肌力」深度科學知識（特別參考怪獸肌力及體能訓練中心 `monstertraining.com.tw` 與何立安博士訪談）以及全站高雅 UI/UX 體驗的需求，進行完整 RPDCA 迭代：

1. **最大肌力 × 肌耐力科學旗艦專區（`#exercise/strength`）**：新增 `MonsterStrengthEnduranceSection.tsx`，將「用常訓替代長照」「先求最大肌力、再求肌耐力（天花板決定地板）」轉化為親民導讀、互動模擬器與四大深度分頁（肌力光譜、怪獸訓練金字塔與人體自然動作三原則、三大能量系統、True/Daily/Easy Max 游刃有餘彈性訓練法）。
2. **「天花板決定地板」互動模擬器**：提供 4 種生活與運動真實負荷情境（20kg 買菜抱孫、32kg 搬水箱、48kg 登山陡坡、60kg 高強度專項），透過調整個人最大肌力（1RM 30–120kg），即時視覺化「相對負荷 %1RM」「相對肌耐力可連續完成次數」與「關節神經安全儲備率」，並標示個體估算範圍。
3. **白話課程、深度條目與全站檢索串聯**：
   - 新增第 65 堂白話小課 `L-MOVE-08`（「最大肌力與肌耐力：為什麼『先練力氣』才能走得遠？」）及其專屬 SVG 金字塔圖解與對照表。
   - 擴充 `strengthData.ts` 新增 `STR-08`（肌耐力生理學與先力量後耐力原則）與 `STR-09`（人體自然動作、三大能量系統與彈性訓練）。
   - 擴充 `glossary.ts`（最大肌力、肌耐力）、`layTerms.ts`（肌耐力、最大肌力、怪獸訓練、何立安、能量系統、彈性訓練）、`searchIndex.ts` 與首頁 `#home` 主打焦點專題卡片。
